安装和部署

在清华源找到软件TeX Live并安装，此时这个软件是一个后缀名为.iso的光驱格式。如果你用的是Windows系统，直接挂载这个光驱，并使用管理员权限运行文件install-tl-windows.bat。配置一个你喜欢的地址，接下来唯一要做的就是等待（可以配置清华源镜像加快下载速度）。大致要等20~60分钟，期间不要手欠去点击absorb这样会前功尽弃。等待“关闭”按钮亮起即可退出安装程序。

  3. 大型项目：使用 latexmk 或 IDE（如 VS Code + LaTeX Workshop）管理编译。

填写正文

  • 使用空行分段。单个换行并不会使文字另起一段，而只是起到使源代码更易读的效果。注意：使用多个空白行并不起到增大间距的作用
  • 段前不用打空格。LaTeX会自动完成文字的缩进，即使手工打了空格，编译时也会将它忽略，如果强行使用，会使你的排版非常糟糕。我们是时候解释一下第一行中ctexart的含义了：它会调用xeCJK宏包，自动处理汉字和其他符号之前的距离。
