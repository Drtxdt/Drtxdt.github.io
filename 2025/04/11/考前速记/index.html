  1. 前缀和和差分互为逆运算

    一维前缀和

    1. 创建前缀和数组 f[i] = f[i - 1] + a[i]
    2. 查询[l, r]区间和 f[r] - f[l - 1]

    二维前缀和

    1. 创建前缀和矩阵 f[i][j] = f[i - 1][j] + f[i][j - 1] - f[i - 1][j - 1] + a[i][j]

    2. 查询以(x1, y1)为左上角，(x2, y2)为右下角的子矩阵的和：

      int t = f[x2][y2] - f[x2][y1 - 1] - f[x1 - 1][y2] + f[x1 - 1][y1 - 1]

    可以看到主对角线和副对角线的符号相反

    一维差分

    1. 创建差分数组

      f[i] = a[i] - a[i - 1]

      也可以利用差分数组的性质

      f[i] += a[1], f[i + 1] -=a[i]

    2. 根据差分数组的性质处理q区间的修改

      f[L] += c, f[R + 1] -= c

    3. 还原经过q次询问之后的a数组

      对我们的差分数组做一次前缀和，即可还原出原数组

      f[i] = f[i - 1] + f[i]
